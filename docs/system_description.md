# Описание моделируемой системы: исследование LDPC-декодеров

## 1. Цель

Исследовать алгоритмы декодирования LDPC-кодов (точность коррекции ошибок, число итераций,
вычислительная сложность) и подготовить эталонную модель, с которой затем будут сравниваться
собственные реализации декодеров (в т.ч. с фиксированной точкой — задел под аппаратную реализацию).

Этап 1 — эталонная модель на стандартных функциях MATLAB (Communications Toolbox + 5G Toolbox).
Этап 2 — собственные реализации декодеров, сравнение с эталоном.

## 2. Структурная схема

```
 ┌────────────┐ u (K бит) ┌──────────────┐ (N бит) ┌──────────────┐ c (E бит) ┌────────────┐  x  ┌─────────┐
 │ Источник   │──────────►│ LDPC-кодер   │────────►│ Согласование │──────────►│ Модулятор  │────►│ Канал   │
 │ (randi)    │           │ nrLDPCEncode │         │ скорости     │           │ BPSK/QPSK/ │     │ AWGN    │
 └────────────┘           └──────────────┘         │ (rv = 0)     │           │ 16QAM      │     │ awgn    │
       │                                           └──────────────┘           └────────────┘     └────┬────┘
       │ эталон u                                                                                     │ y
       ▼                                                                                              ▼
 ┌────────────┐ û (K бит) ┌──────────────┐ LLR (N) ┌──────────────┐ LLR (E)   ┌──────────────────────────┐
 │ Счётчик    │◄──────────│ LDPC-декодер │◄────────│ Восстановл.  │◄──────────│ Мягкий демодулятор       │
 │ BER/FER/   │           │ nrLDPCDecode │         │ скорости     │           │ (точный LLR, σ² известна)│
 │ итераций   │           └──────────────┘         │ (LLR = 0)    │           └──────────────────────────┘
 └────────────┘                                    └──────────────┘
```

| Блок | Реализация (этап 1) | Параметры |
|---|---|---|
| Источник | `randi([0 1], K, B)`, свой `RandStream` на каждую точку | seed |
| Кодер | `nrLDPCEncode(u, bgn)` (5G Toolbox) | BG, Zc |
| Согласование скорости | первые E = K/R бит выхода кодера (rv = 0) | R |
| Модулятор | `pskmod` (BPSK) / `qammod` (QPSK, 16QAM), Gray, единичная средняя мощность | M |
| Канал | `awgn(x, SNR, 0)`; SNR из Eb/N0 через `convertSNR` | Eb/N0, R, log2(M) |
| Демодулятор | `pskdemod` / `qamdemod`, `OutputType="llr"`, `NoiseVariance=σ²` | — |
| Восстановление скорости | непереданные биты: LLR = 0 | — |
| Декодер | `nrLDPCDecode(llr, bgn, maxIter, ...)` | алгоритм, maxIter, α, β, критерий останова |
| Метрики | счётчики ошибок | BER, FER, ср. число итераций |

## 3. Код

**5G NR LDPC (3GPP TS 38.212), базовый граф BG2, Zc = 52 → K = 520, R = 1/2, E = 1040 бит в канал.**
Почему:
- актуальный стандарт, квазициклическая структура, удобная для аппаратной (layered) реализации;
- BG2 — граф, который 5G использует для таких K и R (K ≤ 3840, R ≤ 0.67);
- код короткий — быстро моделируется.

Согласование скорости упрощённое: rv = 0, без filler-бит и без битового перемежения.
Кодер уже выкалывает первые 2·Zc систематических бит (выход N = 50·Zc для BG2),
в канал идут первые E бит, на приёме непереданные биты получают LLR = 0.
Для BPSK это совпадает со стандартным `nrRateMatchLDPC`.

BG, Zc и R задаются в параметрах (`p.bgn`, `p.Zc`, `p.rate`).

## 4. Модель канала

**AWGN, комплексный baseband, 1 отсчёт на символ.** Обоснование:
- стандартная модель для сравнения декодеров — кривые сопоставимы с литературой;
- изолирует свойства декодера от синхронизации/оценки канала;
- дисперсия шума известна точно → LLR точные.

Ось X — **Eb/N0 (на информационный бит)**: SNR = f(Eb/N0, R, log2 M) через `convertSNR`.

## 5. Декодеры (этап 1)

| Алгоритм | `Algorithm` в `nrLDPCDecode` | Комментарий |
|---|---|---|
| Sum-Product (BP, flooding) | `'Belief propagation'` | эталон по качеству, дорогой (tanh/atanh) |
| Layered BP | `'Layered belief propagation'` | сходится быстрее по итерациям |
| Normalized Min-Sum | `'Normalized min-sum'` | layered; `ScalingFactor` α (0.75 по умолч.) |
| Offset Min-Sum | `'Offset min-sum'` | layered; `Offset` β (0.5 по умолч.) |

Критерий останова: синдром = 0 (`Termination="early"`) либо maxIter.

## 6. Параметры моделирования

| Параметр | Значение по умолчанию |
|---|---|
| Код | 5G NR BG2, Zc = 52, K = 520, R = 1/2 |
| Модуляция | BPSK (базовый случай), QPSK, 16QAM |
| Eb/N0 | 0 … 2 дБ, шаг 0.25 дБ |
| maxIter | 50 (свипы: 5, 10, 20, 50) |
| α (NMS) | 0.75 (свип 0.5…1.0) |
| β (OMS) | 0.5 (свип 0…1.0) |
| Останов Монте-Карло на точке | ≥ 100 ошибочных кадров (лимит 1e6 кадров) |
| Пакет кадров | 64 кадра за вызов (векторизация) |

FER = (число кадров, где хотя бы один из K информационных бит декодирован с ошибкой) / (число кадров).
BER = (число ошибочных информационных бит) / (K · число кадров).
Точность: при 100 ошибочных кадрах относительная погрешность FER ≈ ±20 % (95 %).
