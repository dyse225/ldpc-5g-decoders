# dmitry_g: базовые графы 5G и настройки BP

Один run_all.m выполняет три моделирования. Каждая точка Eb/N0 считается всем пулом
из 12 процессов через parfor: процессы обрабатывают разные порции кадров.
Общие функции matlab/ldpc_*.m не изменены.

## Запуск

Откройте в MATLAB папку matlab/experiments/dmitry_g и выполните:

```matlab
run_all
```

По умолчанию maxFrames=1e6. Для быстрой пробы:

```matlab
run_all(1e3)
```

Только одно моделирование, например второе:

```matlab
run_all(1e6,2)
```

Нужны MATLAB R2025b, 5G Toolbox, Communications Toolbox и Parallel Computing Toolbox.
Пул Processes из 12 процессов создаётся автоматически. Если уже открыт другой пул,
скрипт попросит завершить его вручную, не прерывая его автоматически.

## Условия

BPSK, AWGN, R=1/2. Все параметры берутся из ldpc_default_params и переопределяются
локально для эксперимента. NMS α=0,75, OMS β=0,5. Bit-flip: gallager, final.

1. **BG1 против BG2:** BG1 Zc=176, K=3872 и BG2 Zc=52, K=520.
   Пять декодеров: BP, Layered BP, NMS, OMS, bit-flip. maxIter=50, early.
   Мягкие декодеры: 0:0.25:2 дБ, bit-flip: 3:0.5:9 дБ.
2. **Число итераций BP flooding:** BG2 K=520, maxIter=[5 10 20 50 100],
   early, диапазон 0:0.25:2.5 дБ.
3. **Критерий остановки BP flooding:** BG2 K=520, maxIter=50,
   early/max, диапазон 0:0.25:2 дБ.

Только K=3872 и K=520, без BG1 K=528. Всего 17 кривых и 171 точка.
BG1/BG2 выводятся рядом на одном рисунке. Легенды находятся под графиками,
внутри PNG, но вне области кривых.

## Выборка и продолжение

Предел 1e6 относится ко всей точке, а не к каждому процессу. Ошибки и кадры
суммируются по завершённой волне. Расчёт прекращается при достижении 100 ошибочных
кадров либо общего лимита кадров. Последняя волна может дать больше 100 ошибок.
Общий лимит кадров не превышается. Порции содержат от 64 до 512 кадров, а последняя
может быть короче. В конце точки могут работать не все 12 процессов.

Рассчитываются все заданные точки, даже после нулевой FER. Для early сохраняется
досрочная остановка самого декодера по синдрому. Нулевые BER/FER не рисуются
на логарифмической оси, но сохраняются в численных результатах.

MAT, PNG, CSV и контрольные сохранения находятся в results каждого моделирования.
Пробный запуск 1e3 сохраняется отдельно в results_1000. После каждой волны
сохраняется прогресс текущей точки, после каждой точки — checkpoint.
Повторный run_all продолжает расчёт, пропуская завершённые точки.
Для полного пересчёта переименуйте папки results. Параметры кэша проверяются.

Архив поставляется без готовых результатов и старых checkpoint. Первый запуск
считает всё заново. Для работы не нужны старые доп-файлы, MAT или абсолютные пути
к прежней папке. Чтобы положить эксперимент в GitHub, перенесите всю папку dmitry_g
в matlab/experiments исходного проекта. .gitkeep сохраняют пустые папки в Git.

Случайные последовательности детерминированы seed точки и номером порции.
Численные результаты не обязаны совпадать с прежним распределением по точкам:
изменились выборки и размер последней волны. Ускорение зависит от оборудования.
Код подготовлен без запуска моделирований.
